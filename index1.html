布のシミ・洗浄効果を色から測る

BASE（きれいな布）・BEFORE（洗浄前）・AFTER（洗浄後）の3枚の写真から、L*a*b*・白色度・K/S値・色差ΔE00・重量減少率を自動で計算します。すべての処理はブラウザ内で完結し、画像や結果は外部に送信されません。

① 画像を読み込む ② 黒点・白点でキャリブレーション ③ ROI（測定範囲）を指定 ④ ガーゼ／シミを検出 ⑤ 解析を実行 ⑥ PDF / JSON / ZIP で出力

実験情報

BASE 画像をドラッグ＆ドロップ／貼り付け／選択
PC: 画像をドラッグ、またはウィンドウ内で Ctrl+V。タブレット: 長押しで画像を貼り付け。

ROI（測定範囲）とガーゼ検出
「ROI選択」モードで四角をドラッグして範囲を指定し、角のハンドルで調整できます。範囲内でシミ／ガーゼ領域を自動検出します。

解析結果

BASE / BEFORE / AFTER の3画像とROIを準備してから「解析を実行」を押してください。

出力

PDFには実験情報・解析結果・各画像（元画像／キャリブレーション後／ガーゼ検出結果）を収録します。ZIPには元画像・キャリブレーション画像・検出結果画像・experiment.json・PDFをまとめます。
